# Atelier 利用ガイド — 期待されるログ付き

*以下のログ抜粋はフランス語で記録したものです。コードとレベルはどの言語でも同じです（実際のログのメッセージは表示言語で出ます）。*

このガイドでは、Atelier の**すべての機能**をユースケースごとに説明します。それぞれについて：

1. **目的**と**手順**：あなたが行うこと。
2. **通常の流れ**：表示される内容と、**期待されるログ**。
3. **ほかのパターン**：同じように成功する別の流れ。
4. **エラー**：失敗しうること、表示されるメッセージ、ログの行、そして対処。

ログの抜粋は**実際のもの**です。エンドツーエンドのテストで記録しています（[`journaux/`](../journaux/) フォルダー）。時刻、所要時間、ID は毎回変わります。大事なのは**コード**、その**順番**、そして**レベル**です。

## ログの 1 行の読み方
```
12:03:04.567 +2.31s INFO  publish.php.ok [publish.php#2 · 840 ms] Site publié : 42 fichiers {"written":42,"removed":1,"ref":"9f3a01c2"}
│            │      │     │              │                        │                         └ データ（秘密情報は伏せ字）
│            │      │     │              │                        └ メッセージ
│            │      │     │              └ 「publish.php」の 2 番目の流れ、開始から 840 ms
│            │      │     └ 変わらないコード：ドメイン.操作
│            │      └ レベル：TRACE、DEBUG、INFO、WARN、ERROR
│            └ エディターを開いてからの時間
└ 現地時刻
```
- 1 つの**流れ**は `….start` で始まり、途中の段階を経て、`….ok`（成功）、`….fail`（失敗、レベル ERROR、エラー付き）、または `….cancel`（本人が中止）で終わります。
- `php.…` の行はホスティング上の **publish.php** から来たものです。ログが `debug` モードのとき、エディターは応答と一緒にこれらを受け取ります（第0章を参照）。サーバー側のリクエストの参照番号 `req` が付いています。
- `ui.…` の行（クリック、フィールド、ウィンドウ、メッセージ）は**本人が何をしたか**を示します。読みやすくするため、このガイドのほとんどの抜粋では省いていますが、コピーしたログには含まれています。

## レベル
| レベル | 意味 | 例 |
|---|---|---|
| TRACE | とても詳しい。既定では無効 | 要素へのマウスオーバー、メッセージボックスの毎秒の確認 |
| DEBUG | 動作の詳細 | 変更の保存、クリック、ウィンドウを開く |
| INFO | 本人に見える段階 | 公開の完了、プロジェクトを開く |
| WARN | 処理済みの異常、代替動作、想定どおりの拒否 | トークンの拒否、画像が見つからない、AI の API がない |
| ERROR | 失敗 | 公開できない、ローカルに保存できない、JavaScript のエラー |

## 問題を報告するには
1. 問題が起きる操作をもう一度行います。
2. **🐞**（上部バー）をクリックし、**📋 ログをコピー** をクリックします。ホスティングが関係する場合は、先に「サーバーのログ（publish.php）」を開いて **サーバーのログを読み込む** をクリックしてください。その行がコピーに追加されます。
3. 全体をメッセージに貼り付け、何をしたか、何を期待したか、何が起きたかを一文で添えてください。

コピーしたログは環境（ブラウザー、画面、ストレージ、プロジェクト、設定）から始まるので、それを説明する必要はありません。
